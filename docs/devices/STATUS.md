## Full editors and firmware-mapped devices

An editor is a **Full editor** when:

1. Every byte of every object the device sends or keeps (sounds and settings) is a named parameter with the label, range and option list the firmware or manual gives; no "Byte nnh", spare or unknown fields, unless the doc shows the firmware never displays or uses them.
2. Every object reads and writes: the edit buffers, every memory bank (store and fetch), names, and the Branch Library's complete dump.
3. Checked on the hardware, or a documented reason it cannot be that the firmware analysis covers.
4. Every sound object (patch, program, performance, combination, rhythm set...) has a Head Library translator (obj.toCommon / obj.fromCommon) with tests.
5. A multitimbral device has its MIDI channels page.
6. What is left open in the device doc and intdocs/FUTURE_WORK.md is a convenience, not missing data, an unchecked mapping or a missing object.
