# Access Virus TI Desktop

The TI2 editor with this name (`js/devices/defs/access-virus-ti-desktop.js` over `access-virus-ti2.js`): the same host OS, DSP code,
SysEx and USB ports. Evidence and what is not checked: `access-virus-ti-models.md`; the editor itself:
`access-virus-ti2.md`. Not checked on a Virus TI Desktop (only a TI2 Desktop was connected).

## Firmware references from the editor's former page texts

The page texts were rewritten in plain language (2026-11-27); these details they held are kept here.

- The model: its OS image (vti.bin, Software Suite 5.1.7) has the TI2 host code except one byte (000A: 07, in the TI2 image 05), the same DSP code and its own ROM banks (the first TI factory sounds, format 8, shown converted as the OS plays them). Not checked on this model: only a TI2 Desktop was connected.
