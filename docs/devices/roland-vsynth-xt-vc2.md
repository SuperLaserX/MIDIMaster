# Roland V-Synth XT VC-2 (Vocal Designer)

The V-Synth XT's VC-2 engine (OS 2.02, VAPP2). It has its own SysEx model, **00 00 0D** (identity
family 0D 02), and its own parameter map. The full write-up is in
[roland-vsynth-xt.md](roland-vsynth-xt.md), section "VC-2 engine (Vocal Designer)". **Every
parameter** (address, values, size, algorithm group, firmware parameter, place in a `.p02` file),
what each algorithm takes and the effect parameters per type are in
[roland-vsynth-xt-vc2-params.md](roland-vsynth-xt-vc2-params.md) (generated).

What the editor covers:

- System: setup, system (MIDI, controllers, assigns, EQ) and chord memory, and the 8 sampling
  templates (mic EQ and pre-effect). The setup's bank select and program number show as the
  current patch's name (read only); patches are chosen in the Patch page's list.
- The patch: common (algorithm, tempo, beam/pad, tune, scale tune, MFX/chorus/reverb with effect
  parameters named per type), carrier, modulator and vocoder, **shown per algorithm**: parameters
  the algorithm does not use are hidden (a page with none says so), and the oscillator waves are
  lists of the wave numbers the algorithm takes, with their names.
- **Choosing an algorithm** makes the VC-2 load that algorithm's INIT PATCH (every value); the
  editor does the same and says so.
- The 448 user patches (bank select 87/1-4; 87/0 is the preset bank), names read when the XT
  connects.
- **Open .p02 / Save .p02** (the XT's `V:\Internal.vc2\Patch\nnn <name>.p02` in USB storage mode),
  and `.p02` import into the Head Library (also from a drive image).
- **Read wave names** (model 00 24, read only); the factory names 1-54 are shown until then.

## How the tables were made

- **Algorithm groups.** The VC-2 builds its address map at run time: `FUN_89316A40` fills one
  40-byte descriptor per address (byte 0 the size in nibbles, byte 3 the algorithm group, word 2 the
  firmware object, word 3 the firmware parameter id of the first nibble). It was run in Ghidra's
  p-code emulator after the start-up code that copies the initialised data (crt0 copies 8990C758 to
  8992E1BC, 21A64h bytes, and zeroes the BSS), with `tools/roland/ghidra/VsEmuCall.java`:
  `VsEmuCall <out> 89316a40 8c700000 0 0 0 pre:89300040:8930005e 8992e000:7000 899343c0:40` →
  `re/vsynthxt/live/vc2_descriptors.json` (613 addresses: setup, system, template, patch).
  `FUN_8931C5D0(algorithm, group)` says which groups an algorithm takes (group 0: all).
- **Checked on the unit** (`vc2_algo_probe.json`, 2026-11-24): for each algorithm every patch
  parameter was moved by one step and read back. 1407 of 1416 answers agree with the group table; the
  other 9 are value limits (OSC 2 Wave 0 only under some algorithms; 107 = VELO, which the modulator
  controls do not take). Wave numbers were tried from 0 to 70 (the modulator to 127).
- **INIT PATCH.** The patch the unit holds after an algorithm is chosen was read for all 12; algorithm
  0 was chosen after algorithm 1 and after 3 and came out the same (`vc2_alg0_init.json`,
  2026-11-25), so the init does not depend on the patch held before.
- **`.p02` places.** The 16 factory files (`vc2p02/001-016.p02`) were matched against the same
  patches read from the unit (U001-U016, `vc2_u001-016.json`). The packing is the V-Synth's with 8
  zones; the descriptors' firmware ids give each value's bits (`PACK`), and the block each id belongs
  to gives the place: common 0 (VC-2 additions from 4888), MFX 84, chorus 152, reverb 180, carrier
  tone zone 0 at 230 (additions at 4526), modulator tone zone 1, envelopes 854, growl/COSM 2966,
  beam/pad 4054, OSC 1/2 Wave Number in 16 bits at 4996/4998. Four values are stored differently
  (OSC 1 Pitch Octave Shift as a coarse tune, growl intensity/speed + 32768, the modulator wave + 46
  mod 128). All 208 values match in all 16 files; `vc2_map.mjs` refuses to write the table otherwise.
  85 bits of the carrier zone are V-Synth tone fields the VC-2 does not show; written files take them
  from factory patch 001.

Checked on the unit (2026-11-24/25): whole patches, single parameters, names, a system parameter, a
JP-8080 patch through the translator (edit buffer and Store into U448, from the Head Library),
bank select recall, per-algorithm groups and wave numbers, the INIT PATCH of every algorithm, and
the editor's own algorithm change (editor and unit equal byte for byte afterwards). Everything was
put back as it was.
