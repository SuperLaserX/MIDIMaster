# Yamaha DX100 / DX27

Definition: `js/devices/defs/yamaha-dx100.js` over `yamaha-dx4.js` (see `yamaha-tx81z.md`). **Not yet checked on a DX100 or DX27.**

From the DX100 v1.1 firmware (`z:/firmwares/Yamaha_DX100_ROM_v1.1.zip`): the SysEx parser (B0D5: bulk, parameter changes with group byte 12h for the voice, dump requests answered for formats 3 and 4), the maximum table (186B), the INIT VOICE (packed, 2205) and its short screen labels: the label pointer table AB9A points into AC5E-AE51 ("ALG", "FBL", "LW", "L SYNC", "EBS", "KVS", "F", "DET", "AR ", "D1R", "D1L", "D2R", "RR ", "OUT", "RS ", "LS ", "MID.C", " Poly" / " Mono", "PBend", "Full T." / "Fingered", "Porta", " Time", "Foot Sw" with " Sus" / " Por", "saw up", "square", "triangl", "S/Hold"). Labels with display tokens: the print routine (A5AA) shows a byte of 80h or more as the word at AD7E + the byte: 80h "LF", 83h "PM", 86h "AM", 89h "Midi", 8Eh " Ch", 92h "Tape?", 98h " Mode", 9Eh "Porta", A4h "Range", AAh "MW ", AEh "BC ", B2h " Bias ", B9h "Ampli ", C0h "Pitch ". So the LFO and sensitivity pages read LFS, LFD, PMD, AMD, PMS, AMS and the controllers MW Pitch, MW Ampli, BC Pitch, BC Ampli, BC P Bias, BC E Bias. BC P Bias goes to 99 (maximum table 186B; the TX81Z's 100). FC Volume (byte 67, maximum 99) has no DX100 screen and keeps the TX81Z's word. The DX27 shares the DX100's MIDI implementation (one catalog entry). The pitch EG and chorus bytes of the 93-byte voice are kept but not used by these models (the DX21 uses them).

Open: a hardware check; the "Bend Mode" and "Key Shift" screens (ADB0, ADA6) belong to no voice byte read so far.
