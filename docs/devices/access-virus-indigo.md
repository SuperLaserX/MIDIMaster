# Access Virus Indigo

The Virus Indigo (2002, keyboard) runs the Virus B OS 4.9 (its boot text "VIRUS Indigo"; the readme
names it with the b and kb). Its editor is the Virus b's (`js/devices/defs/access-virus-indigo.js`
over `access-virus-abc.js` and the B OS tables): see [access-virus-b.md](access-virus-b.md) and
[access-virus-abc.md](access-virus-abc.md). Not checked on an Indigo (none was connected). The
Indigo 2 runs the C OS (not done yet).
